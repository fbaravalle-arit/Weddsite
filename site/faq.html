FAQ

Dress Code

What is the dress code for Bologna? ¿Cuál es el código de vestimenta para Bolonia? / Qual è il dress code per Bologna?
add

For the events in Bologna, the dress code is Formal. We recommend suits for men and elegant evening wear or cocktail dresses for women. As the ceremony takes place in a historic church, please consider bringing a light wrap or shawl.

What is the dress code for Argentina? ¿Cuál es el código de vestimenta para Argentina? / Qual è il dress code per l'Argentina?
add

The celebrations in Argentina will be Elegant but comfortable. The events will take place outdoors in an estancia setting. We suggest light, breathable fabrics, summer suits (ties optional), and elegant sundresses. Block heels or wedges are recommended for walking on grass.

Additional Companions

Can I bring a plus one? ¿Puedo llevar un acompañante? / Posso portare un accompagnatore?
add

Our weddings are intimate gatherings. If your invitation specifies "and Guest," you are warmly welcome to bring a plus one. Otherwise, we kindly ask that only those named on the invitation attend.

Are children invited? ¿Están invitados los niños? / I bambini sono invitati?
add

We love your little ones! However, please refer to your specific invitation envelope to see if children are included. If you have any questions, please reach out to us directly.

RSVP Deadline

When is the deadline to RSVP? ¿Cuándo es la fecha límite para confirmar asistencia? / Qual è la scadenza per confermare?
add

Due to the complexity of planning multiple events across different continents, we kindly request your RSVP no later than March 15th, 2026. You can RSVP directly through this website using the RSVP tab.
